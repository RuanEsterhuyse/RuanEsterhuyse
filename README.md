# Featured Project

## TeacherOS

TeacherOS is an AI-powered lesson planning platform that transforms authorized curriculum into structured teacher guidance, classroom lesson materials, and editable Google Slides.

### Highlights

- AI-powered lesson generation
- Teacher Playbooks
- Google Slides publishing
- Curriculum registration and lesson indexing
- Local-first architecture
- Automated testing
- Continuous Integration (GitHub Actions)
- Open-source portfolio project

👉 **Repository:** https://github.com/RuanEsterhuyse/TeacherOS
